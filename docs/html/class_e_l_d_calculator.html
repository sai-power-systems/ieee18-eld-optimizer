Detailed Description

Calculator class for performing Lambda Iteration-based Economic Load Dispatch (ELD).

Assumes generator cost function: 

 F(P) = a + bP + cP²

Incremental cost: 

 dF/dP = b + 2cP

At optimum: 

 λ = b + 2cP

Therefore: 

 P = (λ - b) / (2c)
